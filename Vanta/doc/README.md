## Funzionalità mostrate

- Percorso a domande con pulsanti selezionabili (nessun codice da scrivere)
- Variabili con valore fisso o richiesto all'utente a runtime (input/scanner)
- Tipi di dato: numero intero, numero decimale, testo, lista di numeri
- Operazioni: somma, sottrazione, moltiplicazione, divisione, resto, potenza,
  radice quadrata, valore assoluto, confronto, unione di testo
- Operazioni sulle liste: somma, media, massimo, minimo, lunghezza, ordinamento
- Operazioni incatenate (il risultato di un passaggio può essere riusato nel successivo)
- Doppia modalità di output: programma da terminale o piccolo wizard con finestra grafica
- Codice Python generato leggibile, salvabile in un file `.py` ed eseguibile con un clic
